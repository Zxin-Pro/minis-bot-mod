# Minis Bot Mod — 像真人玩家的 AI 机器人模组

> **NeoForge 1.21.1 · 纯服务端模组（客户端无需安装）**

## 功能

- 🤖 **一个像玩家的机器人实体** — 会走、会跑、会干活
- ⛏️ **自动挖矿** — 支持所有矿石，**专门优化了下界远古残骸挖掘**
- 🌲 **自动砍树** — 找树、砍树、收集木头
- 🌱 **自动植树** — 种树苗，用骨粉催熟
- ⚔️ **自动战斗** — 被攻击自动反击，主动巡逻清怪
- 👣 **跟随玩家** — 跨维度传送跟随
- 🏠 **回家** — 自动回到重生点
- 💬 **游戏内命令** — `/zxbot` 全套命令控制

## 安装

1. 你的服务器需要安装 [NeoForge 21.1.112+](https://neoforged.net/)
2. 把 `minis-bot-mod-*.jar` 放入服务器的 `mods/` 文件夹
3. 重启服务器

**客户端不需要安装任何东西。**

## 使用方法

### 生成机器人

```
/zxbot spawn [名字]
```

示例：`/zxbot spawn 矿工小王`

### 控制命令

| 命令 | 说明 |
|------|------|
| `/zxbot help` | 查看帮助 |
| `/zxbot status` | 查看机器人状态、位置、血量、任务 |
| `/zxbot mine <矿物>` | 挖矿。支持：`diamond`, `ancient_debris`, `iron`, `gold`, `all` |
| `/zxbot nether` | **去下界挖远古残骸（一键操作）** |
| `/zxbot chop` | 砍树 |
| `/zxbot farm` | 种树 |
| `/zxbot fight` | 进入战斗模式 |
| `/zxbot follow <玩家>` | 跟随指定玩家 |
| `/zxbot come` | 传送到你身边 |
| `/zxbot come <玩家>` | 传送到指定玩家 |
| `/zxbot stop` | 停止所有任务 |
| `/zxbot inventory` | 查看背包 |
| `/zxbot home` | 回家（回到主世界重生点） |
| `/zxbot say <消息>` | 让机器人在游戏里说话 |

### 右键交互

**在游戏内右键点击机器人**，直接查看状态报告。

### 被攻击自动反击

机器人被攻击时会自动切换为战斗模式反击敌人。

## 如何挖远古残骸

```
# 1. 确保机器人已生成
/zxbot spawn 矿工

# 2. 一键开始挖远古残骸（自动进入下界，找到 Y=8~22 层）
/zxbot nether

# 3. 查看进度
/zxbot status

# 4. 让他回来
/zxbot come
```

机器人会自动：
1. 传送到下界
2. 下降到 Y=8~22 层（远古残骸生成层）
3. 自动搜索并挖掘 `ancient_debris`
4. 挖到后自动拾取掉落物

## 构建

```bash
# 需要 JDK 21
./gradlew build
```

构建产物在 `build/libs/minis-bot-mod-*.jar`
